# Vendored skills — heygen-com/hyperframes

The skills in this directory (`hyperframes`, `hyperframes-cli`, `hyperframes-registry`, `gsap`,
`website-to-hyperframes`, `claude-design-hyperframes`) are vendored **unmodified** from
[heygen-com/hyperframes](https://github.com/heygen-com/hyperframes). Exact versions are pinned by
content hash in [`skills-lock.json`](../../skills-lock.json); `.claude/skills/<name>` are symlinks here.

([`LICENSE-hyperframes`](LICENSE-hyperframes)) — not under this repository's MIT license.
To update them, re-install from upstream and refresh `skills-lock.json`; do not edit in place.
