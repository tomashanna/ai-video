## Methodology REVISION — MAX DETAIL sampling (post 2026-05-19 GAP #20 codification)

> **Trigger**: matadero iter 1-4 architect codified countdown style basado en ref-XX.md sampling cada 5s. Resulted in INCORRECT analysis: "2/6 had countdown" → audit direct frame verification revealed 4/4 universal. Countdown windows fell between sampled frames.
>
> **Root cause anti-pattern #10**: docs trust without direct verification. Architect/auditor sampling 5s gaps + accepting findings sin frame-by-frame validation.

### Revised sampling spec (MAX DETAIL)

**Hook + decision_1 windows (typically 0-30s)**:
- Sample every **0.5s** for first 30s of each canonical ref
- Capture every UI/audio event change (name labels appear, countdown start/digit-change/end, freeze, filter activate, etc.)

**Rest of video (30s → end)**:
- Sample every **1s**
